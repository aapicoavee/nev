# Quality Issue Monitor

Key-in system and dashboard for **TQO findings** and **road test rejections**.

- **Key in:** photo (up to 3), issue, bay, sub (IP / Door / Front Sub / Rear Sub), made by (operator / PIC), date, body/VIN, remarks
- **Dashboard:** KPIs with change vs previous period, daily trend, by-sub share, Pareto of issues, bay × sub heatmap, top makers, oldest open issues
- **Records:** search, filters, photo detail panel, open/close, delete, copy as CSV

## Where the data lives

Live data (entries and photos) is stored by Claude's shared artifact storage, so use the team link for real work:
https://claude.ai/artifact/62h22JN83ZAfXznA1WP6Z9

This repository holds the source code. Opened outside Claude (e.g. GitHub Pages), the page runs in preview mode: entries show on screen but are not saved.
